Unity ML Agents

A Machine Learning experience using Python and Unity.

About

This was a small side project for college. We used ML-Agents and Unity to train an agent to collect a target without hitting the walls.

Process

It started with following a tutorial to get everything installed and working together. Using the command prompt, I installed Python and all the packages needed for ML-Agents to work with Unity. After some tweaking, changes, and installing specific versions of software, I was able to start training the agent by running a command and ensuring it was rewarded when hitting the target and punished when hitting the wall.
